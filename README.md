# Murim Sandbox — ต้นแบบออนไลน์

ต้นแบบเมือง 2.5D ภาพฉายเฉียงสำหรับโทรศัพท์และคอมพิวเตอร์ พร้อมหน้าต่อสู้โทนเครื่องพกพา ใช้ Phaser 4.2.1, Node.js และ WebSocket; ฉากเมืองใช้ภาพต้นแบบ จอมยุทธ์และหุ่นฝึกใช้ภาพนิ่งพิกเซลอาร์ต และเปิดช่องใส่ spritesheet แล้ว

## เริ่มเล่น

ติดตั้ง Node.js 22 หรือใหม่กว่า แล้วรันในโฟลเดอร์ที่โคลนจาก repository:

```powershell
npm ci
npm start
```

เปิด http://localhost:3000 ในเบราว์เซอร์ ใช้เบราว์เซอร์ปกติและหน้าต่างส่วนตัวแยกกันเพื่อทดลองผู้เล่นสองคน หากใช้โทรศัพท์ในเครือข่ายเดียวกัน ให้เปิด `http://<IP-ของเครื่อง>:3000` และอนุญาตการเชื่อมต่อในไฟร์วอลล์เมื่อจำเป็น

ตัวละครเริ่มในเขตปลอดภัย ใช้ปุ่มทิศทางสี่ทิศเพื่อเดิน และกดขวาค้างเพื่อออกจากเมือง แตะ MENU เพื่อดูสถานะและใช้คำสั่งท้าผู้เล่นใกล้สุด ปุ่ม A ใช้เลือกหรือยืนยัน ปุ่ม B ใช้ย้อนกลับหรือเปิดกระเป๋ายาระหว่างต่อสู้ เมื่อต้องการฝึกคนเดียว ให้เดินใกล้หุ่นฟางที่จุดเริ่มต้นแล้วเลือก MENU → ฝึกกับหุ่น หุ่นไม่โจมตีตอบ ไม่มีของตกหรือรางวัลปราณ และฝึกซ้ำได้ ต่อสู้แบบผลัดเทิร์นโดยเลือกโจมตี ใช้ปราณ ยา ป้องกัน หรือหนี ปราณตกค้างสลายตามเวลา ผู้เล่นดูดซับหรือเก็บไอเทมจากศพใกล้ตัวได้

## ทดสอบ

```powershell
npm test
```

สถานะบันทึกที่ `server/data/state.json`; token ของตัวละครเก็บใน localStorage ของเบราว์เซอร์ ไฟล์สถานะนี้เป็นข้อมูลทดลองและไม่ได้ถูกเสิร์ฟผ่าน HTTP การล้างข้อมูลเบราว์เซอร์จะทำให้เข้าถึงตัวละครเดิมไม่ได้

## ภาพพิกเซล

อ่าน [วิธีเตรียม spritesheet](src/client/PIXEL-ASSETS.md) และตั้งค่าชั้นภาพใน `src/client/assets.js` ภาพปัจจุบันเป็นภาพชั่วคราว ระบบรองรับชั้น body, clothing, weapon ร่วมกันทุกตัวละคร และมีช่องใส่ภาพนิ่งต่อสู้ ยังไม่มีอุปกรณ์รายตัวหรือภาพเคลื่อนไหวต่อสู้

## ขอบเขตต้นแบบ

ต่อสู้ 1 ต่อ 1, แผนที่เมืองทดลองแบบภาพเต็มจอเดียว พื้นที่เดินกำหนดโดยเซิร์ฟเวอร์ให้สอดคล้องกับภาพ (ภาพแบนจึงไม่บังตัวละครแยกชั้น และพื้นที่ชนเป็นต้นแบบโดยประมาณ), เขตปลอดภัย, ปราณและการขัดสมาธิ, ตายถาวร, ของตกและประวัติ, ดูดซับ, เกิดใหม่ และสถานะออฟไลน์ปลอดภัย ตัวเลขทั้งหมดเป็นค่าทดลอง ยังไม่มีระบบสำนัก แผนที่เกาหลีจริง NPC ที่มีพฤติกรรมนอกจากหุ่นฝึก พิษที่ผู้เล่นใช้ได้ ศาล ประหาร ตีบวก เศรษฐกิจ หรือระบบสงคราม

ใช้ bearer token แบบต้นแบบ ไม่มีระบบบัญชีหรือการเข้ารหัสที่พร้อมใช้งานจริง เหมาะกับการทดสอบในเครือข่ายที่เชื่อถือได้เท่านั้น ไม่ใช่เซิร์ฟเวอร์เปิดให้สาธารณะ; GitHub repository หรือ GitHub Pages เพียงอย่างเดียวไม่รันเซิร์ฟเวอร์ WebSocket ให้

## เอฟเฟกต์ PixelFX

โปรเจกต์มีซอร์สเอฟเฟกต์ PixelFX ทั้ง 244 รายการที่ `public/vendor/pixelfx/src/fx/` และ [รายการเอฟเฟกต์](public/vendor/pixelfx/CATALOG.md) คำสั่งต่อสู้พื้นฐานเชื่อมกับเอฟเฟกต์แล้ว: โจมตี, ใช้ปราณ, ใช้ยา, ป้องกัน และหนี การกำหนดเอฟเฟกต์ต่อสู้อยู่ที่ `src/client/battle-fx.js`; ฉากโลกใช้วงแหวน Rune Circle สำหรับนั่งสมาธิ (ฟ้า) ยาบำรุง (เขียว) และดูดซับปราณ (ม่วง) ตั้งค่าใน `src/client/world-fx.js`; เอาต์พุตเป็นภาพประกอบจากเหตุการณ์เซิร์ฟเวอร์ ไม่ตัดสินผลเกม
