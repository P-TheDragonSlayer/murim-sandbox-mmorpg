# ใส่ภาพพิกเซลตัวละคร

ตัวต้นแบบใช้กล่องวาดด้วย Phaser เมื่อยังไม่มีภาพ จึงเปิดเกมได้โดยไม่ต้องดาวน์โหลดภาพเพิ่มเติม ตั้งค่าภาพใน `assets.js` เท่านั้น โดยใส่ไฟล์ PNG ใต้โฟลเดอร์โปรเจกต์ซึ่งเซิร์ฟเวอร์สามารถให้บริการได้ เช่น `public/art/body.png` แล้วกำหนด `url: '/public/art/body.png'` ให้ layer ที่ต้องการ

## ข้อตกลง spritesheet

- Layer ที่รองรับตอนนี้: `body`, `clothing`, `weapon` เรียงซ้อนตาม `depth` และใช้เฟรมเดียวกัน แผ่นของทุกชั้นต้องมีจำนวนเฟรม ขนาดเฟรม ตำแหน่งตัวละคร และลำดับเฟรมตรงกันทุกช่อง
- ภาพ PNG มีพื้นหลังโปร่งใส จัดช่องขนาดเท่ากันเรียงซ้ายไปขวาโดยไม่มีขอบหรือช่องว่างระหว่างเฟรม ปรับ `frameWidth` และ `frameHeight` ของแต่ละ layer ตามภาพจริง
- `originX: 0.5, originY: 1` คือจุดกลางล่างของแต่ละเฟรม ให้วางตำแหน่งเท้าตรงกันทุกเฟรมและทุกชั้น ปรับ `scale` ด้วยเลขเดียวกันเพื่อความตรงกัน
- `CHARACTER_ANIMATIONS` กำหนดเฟรม `idle` และ `walk` แบบ index เริ่มที่ 0 และ frame rate ร่วมกันทุกชั้น ตัวอย่างปัจจุบัน: เฟรม 0 ยืน, เฟรม 1–4 เดิน ปรับช่วงให้ตรงกับไฟล์ได้
- ภาพหันขวาเป็นต้นฉบับ; เกมกลับภาพแนวนอนเมื่อทิศเป็น -1 ภาพซ้ายที่ต้องต่างจริง ๆ ยังไม่ได้รองรับ
- หากยังไม่มี `body` จะแสดงกล่องแทน สามารถเพิ่ม `clothing`/`weapon` เพื่อทดลอง overlay ได้ ภาพทุกชั้นใช้ร่วมกันทุกตัวละครในต้นแบบ; **ยังไม่มี** การเลือกชุด/อาวุธรายคน, animation โจมตี, ทิศทางอิสระ หรือการเรียงชั้นด้านหน้าหลังตามท่า
- `pixelArt: true` ทำให้ใช้การแสดงภาพแบบคมชัด ควรทดสอบภาพจริงบนโทรศัพท์และตรวจขอบ/เฟรมก่อนนำไปใช้

`assets.js` เป็นโค้ดในโปรเจกต์ ไม่ใช่ข้อมูลจากผู้เล่น: อัปเดตแล้วรีเฟรชหน้าและตรวจว่าไม่มี 404 ใน browser developer tools ก่อนใช้งาน

## เมือง 2.5D และฉากต่อสู้

เมืองใช้ตำแหน่งโลกสองแกนแปลงเป็นภาพฉายเฉียงและจัดลำดับภาพตามตำแหน่งเท้า เป็น 2.5D ด้วยภาพ 2D ไม่ใช่โมเดล 3D อาคารและพื้นในปัจจุบันวาดด้วยโค้ด ยังไม่มีระบบโหลด tileset หรือ collision ของอาคาร ฉากต่อสู้ตั้งภาพ PNG โปร่งใสแยกสำหรับผู้เล่นและคู่ต่อสู้ได้ผ่าน `BATTLE_ART` ใน `assets.js` หากไม่มีภาพหรือโหลดไม่สำเร็จจะใช้ภาพตัวแทนจาก CSS ภาพต่อสู้ชุดนี้ใช้ร่วมกันทุกตัวละครและยังไม่รองรับภาพเคลื่อนไหวหรืออุปกรณ์รายตัว
