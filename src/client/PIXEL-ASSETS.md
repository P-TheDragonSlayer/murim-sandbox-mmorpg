# ใส่ภาพพิกเซลตัวละคร

ตัวต้นแบบมี spritesheet จอมยุทธ์และภาพนิ่งหุ่นฝึก; หาก spritesheet โหลดไม่ได้จะใช้ภาพนิ่งจอมยุทธ์ และหากภาพนิ่งโหลดไม่ได้จึงแสดงกล่องวาดด้วย Phaser ตั้งค่าภาพใน `assets.js` โดยใส่ไฟล์ PNG ใต้โฟลเดอร์โปรเจกต์ซึ่งเซิร์ฟเวอร์สามารถให้บริการได้

## ข้อตกลง spritesheet

- Layer ที่รองรับตอนนี้: `body`, `clothing`, `weapon` เรียงซ้อนตาม `depth` และใช้เฟรมเดียวกัน แผ่นของทุกชั้นต้องมีจำนวนเฟรม ขนาดเฟรม ตำแหน่งตัวละคร และลำดับเฟรมตรงกันทุกช่อง
- ภาพ PNG มีพื้นหลังโปร่งใส จัดช่องขนาดเท่ากันเรียงซ้ายไปขวาโดยไม่มีขอบหรือช่องว่างระหว่างเฟรม ปรับ `frameWidth` และ `frameHeight` ของแต่ละ layer ตามภาพจริง
- `originX: 0.5, originY: 1` คือจุดกลางล่างของแต่ละเฟรม ให้วางตำแหน่งเท้าตรงกันทุกเฟรมและทุกชั้น ปรับ `scale` ด้วยเลขเดียวกันเพื่อความตรงกัน
- `CHARACTER_ANIMATIONS` กำหนดเฟรม `idle` และ `walk` แบบ index เริ่มที่ 0 และ frame rate ร่วมกันทุกชั้น แผ่นปัจจุบันมี 4 คอลัมน์ 2 แถว ขนาดเฟรมละ 128×128: เฟรม 0 ยืน, เฟรม 0–3 เดิน, เฟรม 4–7 ฟันในฉากต่อสู้
- ภาพหันขวาเป็นต้นฉบับ; เกมกลับภาพแนวนอนเมื่อทิศเป็น -1 ภาพซ้ายที่ต้องต่างจริง ๆ ยังไม่ได้รองรับ
- หากไม่มี `body` จะใช้ภาพนิ่งจอมยุทธ์ และถ้าภาพนิ่งโหลดไม่ได้จึงแสดงกล่องแทน สามารถเพิ่ม `clothing`/`weapon` เพื่อทดลอง overlay ได้ ภาพทุกชั้นใช้ร่วมกันทุกตัวละครในต้นแบบ; **ยังไม่มี** การเลือกชุด/อาวุธรายคน, ทิศทางอิสระ หรือการเรียงชั้นด้านหน้าหลังตามท่า
- `pixelArt: true` ทำให้ใช้การแสดงภาพแบบคมชัด ควรทดสอบภาพจริงบนโทรศัพท์และตรวจขอบ/เฟรมก่อนนำไปใช้

`assets.js` เป็นโค้ดในโปรเจกต์ ไม่ใช่ข้อมูลจากผู้เล่น: อัปเดตแล้วรีเฟรชหน้าและตรวจว่าไม่มี 404 ใน browser developer tools ก่อนใช้งาน

## เมือง 2.5D และฉากต่อสู้

เมืองใช้ตำแหน่งโลกสองแกนและจัดลำดับภาพตามตำแหน่งเท้า เป็น 2.5D ด้วยภาพ 2D ไม่ใช่โมเดล 3D พื้นหลังเมืองเป็นภาพเดียวพร้อมพื้นที่กำหนดการชน ฉากต่อสู้ใช้แถวที่สองของ spritesheet เมื่อเซิร์ฟเวอร์ยืนยันการโจมตี พร้อมอาการถูกโจมตีของเป้าหมาย หากโหลด spritesheet ไม่สำเร็จจะใช้ภาพนิ่ง และถ้าภาพนิ่งโหลดไม่ได้จะใช้ภาพตัวแทนจาก CSS ภาพชุดนี้ใช้ร่วมกันทุกตัวละครและยังไม่รองรับอุปกรณ์รายตัว

## ภาพจอมยุทธ์และหุ่นฝึกต้นแบบ

`public/art/characters/murim-wanderer-v1.png` และ `training-dummy-v1.png` เป็นภาพนิ่ง PNG โปร่งใส ส่วน `murim-wanderer-sprites-v1.png` เป็น spritesheet จอมยุทธ์สำหรับเดินและฟัน ภาพและสีที่ใช้ทุกตัวละครเหมือนกันในต้นแบบ ยังไม่มีระบบถอดเปลี่ยนอุปกรณ์
