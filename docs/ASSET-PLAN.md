# แผน Asset — Murim Sandbox

สถานะ: แผนเป้าหมายสำหรับเกมช่วงแรก ไม่ใช่รายการที่ผลิตเสร็จแล้ว จำนวนทุกชุดใช้วางแผนและปรับได้หลังทดสอบ **หนึ่งชุดอาจมีหลายไฟล์ หลายทิศ หรือหลายเฟรม** ห้ามนับจำนวนฉากเท่ากับจำนวนไฟล์ ภาพอ้างอิงจากเกมอื่นใช้กำหนดบรรยากาศ ไม่คัดลอกภาพ ตัวละคร โลโก้ หรือ UI เฉพาะ

## สถานะที่มีจริง

- `CONCEPT-TOWN-01`: `public/art/backgrounds/murim-town-dusk-concept-v1.png` — ภาพ AI แนวทางสีและองค์ประกอบ ยังไม่ใช่แผนที่เดินได้หรือ tileset

- `BUILD-01`: `public/art/objects/hanok-house-v1.png` — AI สร้างด้วยเครื่องมือสร้างภาพในตัว; PNG RGBA 1536×1024 นำเข้าในเมืองทดลอง 1 หลัง สถานะรอตรวจงานภาพ; ยังต้องตรวจขอบโปร่งใส แยกหลังคา และเพิ่ม collision ก่อนใช้จริง
- ร่าง เสื้อ อาวุธ ภาพต่อสู้ และบ้านอื่นในเกมยังเป็น placeholder; ยังไม่มีชุดตัวละครถอดเปลี่ยนที่ใช้งานจริง

สถานะที่ใช้: `มีแล้ว—ทดลอง`, `รอสร้าง`, `กำลังสร้าง`, `รอตรวจในเกม`, `ผ่านตรวจ`, `พักไว้`; ค่าเริ่มต้นทุก ID ด้านล่างเป็น `รอสร้าง` เว้นแต่ระบุอย่างอื่น P0 คือฉากทดลองแรก P1 คือชุดเกมเริ่มต้น P2 คือขยายโลก

## ข้อกำหนดการผลิต

Phaser 4.2.1, โทรศัพท์แนวตั้ง จอเกม 16:9, โลก 2.5D ใช้ภาพ 2D มุมมองเอียง กล้องและเซิร์ฟเวอร์ควบคุมตำแหน่ง; การต่อสู้ผลัดเทิร์นแยกจอ ภาพฉากเดียวที่มีบ้านกับพื้นอบรวมกันไม่ถือว่าเป็น tileset, collision, หรือชั้นบังตัวละคร

ล็อกสไตล์โดยใช้ `CONCEPT-TOWN-01` เป็นภาพอ้างอิง: เมืองเกาหลีแฟนตาซี หลังคาฮันอก หิน แสงโคม เฉดหินอุ่น เทา น้ำตาล เขียวหม่น พิกเซลชัด มุมกล้องและแสงสอดคล้องกัน ให้เจน/ตรวจ **ทีละชิ้น** บันทึกที่มา รุ่นไฟล์ ขนาด จุดยึด การอนุมัติ และทดสอบในเกมก่อนขยาย ไม่สร้างอัตโนมัติเป็นชุดใหญ่ก่อนตรวจผลงาน

ชิ้นอาคาร/ต้นไม้/อุปกรณ์: PNG โปร่งใสจริง มีพื้นที่ขอบ ปักจุดยึดกลางล่าง; พื้นและทางเดิน: ทำเป็น tile grid และทดสอบต่อกัน 3×3 พร้อมแผน collision; อย่าสมมติว่า AI ทำ grid หรือ alpha ถูกต้อง ต้องตรวจจริง กำหนดขนาดหลังวัดสเกลในเกม ไม่อ้างขนาดที่โมเดลรับประกันไม่ได้

ตัวละครโลก: เสนอ 4 ทิศ front/back/left/right และท่า idle/walk; ทุกชั้นต้องตรง frame count, anchor, canvas, animation timing และทดสอบการเรียงหน้าหลัง; การ flip ใช้ได้เมื่อทิศและอุปกรณ์เหมาะสมเท่านั้น ไม่สร้างตัวอย่าง 4 ทิศแล้วอ้างว่าโค้ดรองรับแล้ว ปัจจุบันรองรับ idle/walk และ flip แนวนอนเท่านั้น จึงต้องเพิ่มระบบก่อนใช้ครบ 4 ทิศ

## ลำดับเริ่มทำทีละชิ้น

1. `BUILD-01` บ้านฮันอกเล็ก แบบโปร่งใส 1 หลัง — ทดลองแยกพื้น/จุดยึดก่อน; ภาพที่เจนยังไม่ถือว่า collision หรือแยกหลังคาสำเร็จโดยอัตโนมัติ
2. `TILE-01` พื้นหินเมือง — ตรวจรอยต่อ, ขนาด grid, เส้นทางชน และ test 3×3

4. จัดเมือง SC-01 ทดลองการบังและการเดินจริง; ทำ `CHAR-BODY-01` + ชุด 1 + อาวุธ 1 และทดสอบ idle/walk
5. ทดลองฉากต่อสู้ SC-11, ป่า SC-04 และไอคอนชุดเล็ก ก่อนขยายเป็นรายการ P1/P2
